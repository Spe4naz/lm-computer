# Инструменты

Модель получает 12 инструментов. Файловые операции ограничены рабочей папкой,
`shell_run` выполняется с правами пользователя после подтверждения.

| Инструмент | Риск | Подтверждение | Что делает |
|---|---|---|---|
| `computer_status` | низкий | нет | workspace, shell, режим подтверждений, остаток автопринятия |
| `fs_list` | низкий | нет | список файлов и папок (до 500 записей) |
| `fs_read` | низкий | нет | чтение UTF-8 текста, до 1 МиБ |
| `fs_write` | средний | нет | создать/перезаписать файл, до 5 МиБ, создаёт папки |
| `fs_append` | средний | нет | дописать текст в файл |
| `fs_mkdir` | низкий | нет | создать папку с родителями |
| `fs_move` | средний | **да** | переместить/переименовать, `overwrite` |
| `fs_delete` | высокий | **да** | переместить в корзину (не удаляет навсегда) |
| `fs_search` | низкий | нет | поиск по именам и содержимому, glob, до 200 результатов |
| `system_info` | низкий | нет | ОС, CPU, память, uptime, workspace |
| `open_path` | средний | **да** | открыть файл/папку в файловом менеджере |
| `shell_run` | высокий | **да** | команда на хосте, `cwd`, `timeout_sec` |

## Ограничения

| Что | Лимит |
|---|---|
| Чтение файла | 1 МиБ, только UTF-8 текст |
| Запись файла | 5 МиБ |
| Список каталога | 500 записей |
| Поиск | 10 000 просмотренных файлов, 5 секунд |
| Вывод команды | `maxOutputBytes`, по умолчанию 64 КиБ |
| Таймаут команды | `shellTimeoutSec` или `timeout_sec`, максимум 600 с |
| Тело JSON-запроса | 8 МиБ |
| Загрузка файла через REST | 8 МиБ |

## Удаление

`fs_delete` не удаляет данные: файл или папка переезжает в

```text
~/.config/lm-computer/trash/<время>-<имя>
```

Оттуда её можно вернуть вручную. Корзина не чистится автоматически.

## shell_run

- `command` — командная строка;
- `cwd` — каталог относительно workspace (по умолчанию сам workspace);
- `timeout_sec` — 1–600, но не больше `shellTimeoutSec`.

Блокируются независимо от подтверждения:

- `sudo`, `doas`, `pkexec`, `su`;
- `mkfs`, `wipefs`, `fdisk`, `parted`, `sgdisk`, `gdisk`;
- `dd ... of=/dev/...`;
- `shutdown`, `reboot`, `poweroff`, `halt`;
- `chmod -R 777 /`;
- fork bomb;
- `rm -rf /`, `rm -rf ~`, `rm -rf $HOME`.

Окружение команды ограничено allowlist (`PATH`, `HOME`, `LANG`, `TERM`,
`TMPDIR` и подобные): токены и произвольные переменные сессии не передаются.

Denylist — защита от случайных разрушительных команд, **не sandbox**. После
подтверждения команда работает с правами пользователя и может читать
`~/.ssh`, токен плагина и файлы вне workspace. Не включайте автопринятие, если
не доверяете модели.

## Где посмотреть актуальный список

```bash
TOKEN="$(cat ~/.config/lm-computer/token.txt)"
curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:1236/api/tools
```

Ответ содержит `name`, `description`, `risk` и `approval` для каждого
инструмента.
